## Overview

**EA Gameplay Systems** represents the player-facing gameplay features developed for **East Atlanta Stories**, including transportation systems, jobs, business systems, gang systems, interaction mechanics, customization features, and world-based gameplay infrastructure.

These systems are designed to create a more engaging and custom roleplay experience than a basic stock FiveM server.

This repository serves as a public technical case study.

Production source code, configuration, assets, and proprietary implementation remain private.

- Bus spawn logic

- Route logic
- Custom spawn positioning
